# Cloud Environment Setup

## 0. Prerequisites

The following tools must be installed before proceeding.

| Tool | Purpose | Install |
|---|---|---|
| Docker | Run containers | [docs.docker.com](https://docs.docker.com/engine/install/) |
| openssl | Generate keys and certificates | `brew install openssl` |
| keytool | Generate JKS keystore | Bundled with JDK (`brew install openjdk`) |
| python3 | Run JWK update script | `brew install python` |

The following must also be prepared:

- Domains for Issuer, AS, and Frontend
- ALB configuration and ACM certificate (TLS terminated at ALB)

## 1. Directory Structure

```
<working directory>/
├── eudi-srv-issuer-oidc-py/
│   └── script/
│       ├── setup-certs.sh
│       ├── generate_local.sh
│       ├── certs/                      ← generated by setup-certs.sh
│       │   ├── trusted_cas/            ← generated by setup-certs.sh
│       │   ├── privKey/                ← generated by setup-certs.sh
│       │   └── verifier/               ← generated by setup-certs.sh
│       └── patches/
├── eudi-srv-web-issuing-eudiw-py/
└── eudi-srv-web-issuing-frontend-eudiw-py/
```

## 2. Generate `_local` files

```bash
bash eudi-srv-issuer-oidc-py/script/generate_local.sh
```

## 3. Generate certificates and keys

Use the `--cloud` flag to skip mkcert and iOS Simulator related steps.

```bash
bash eudi-srv-issuer-oidc-py/script/setup-certs.sh --cloud
```

The following will be generated:

- `certs/trusted_cas/` — IACA / DS certificates
- `certs/privKey/` — Private keys
- `certs/verifier/keystore.jks` — Verifier keystore
- JWK in `metadata_config_local.json` is automatically updated with the new public key

## 4. Edit configuration files

Copy each `_local` file and update the following parameters.

### eudi-srv-issuer-oidc-py

**Edit `config_local.json`**

| Parameter | Change |
|---|---|
| `domain` | Cloud domain of AS (e.g. `as.example.com`) |
| `base_url` | Cloud URL of AS (e.g. `https://as.example.com`) |
| `authorization_redirect_url` | Cloud URL of Issuer + `/auth_choice` |
| `op.server_info.add_ons.dpop.kwargs.allowed_htu` | Cloud URLs of Issuer and AS |
| `webserver.server_cert` | Remove or set to `null` |
| `webserver.server_key` | Remove or set to `null` |

**Edit `openid-configuration_local.json`**

Replace all occurrences of `localhost:6005` with the cloud URL of AS.

### eudi-srv-web-issuing-eudiw-py

**Copy `app/.env.local` and edit**

| Parameter | Change |
|---|---|
| `SERVICE_URL` | Cloud URL of Issuer |
| `DEFAULT_FRONTEND_URL` | Cloud URL of Frontend |
| `AUTH_SERVER_INTERNAL_URL` | Cloud URL of AS |
| `VERIFY_USER_ENDPOINT` | Cloud URL of AS + `/verify/user` |
| `SAML_SP_ENTITY_ID` | Cloud URL of Issuer |
| `SAML_SP_ACS_URL` | Cloud URL of Issuer + `/saml/acs` |

**Edit `docker-compose.yml`**

Remove the TLS options from the `command` of `issuer_backend_local`.

```yaml
command: flask run --host=0.0.0.0
```

**Edit `app/metadata_config/openid-configuration_local.json`**

Replace all occurrences of `localhost:6005` with the cloud URL of AS.

> Endpoint URLs in `metadata_config_local.json` are automatically replaced by the value of `SERVICE_URL` — no manual changes required.

### eudi-srv-web-issuing-frontend-eudiw-py

**Copy `.env.local` and edit**

| Parameter | Change |
|---|---|
| `SERVICE_URL` | Cloud URL of Frontend |
| `ISSUER_URL` | Cloud URL of Issuer |
| `OAUTH_URL` | Cloud URL of AS |

**Edit `docker-compose.yml`**

Remove the TLS options from the `command` of `issuer_frontend_local`.

```yaml
command: flask run --host=0.0.0.0
```

## 5. Start containers

```bash
cd eudi-srv-web-issuing-eudiw-py
docker compose --profile local up -d
```

---

> **Note on order:** `generate_local.sh` must be run before `setup-certs.sh`.
> Running them in reverse order will cause `generate_local.sh` to overwrite the JWK updated by `setup-certs.sh`.
